# Reel C — "Owner's Invite" · Marwari talking-head ad script

**Concept:** the owner of Shivaa Jewels on camera, in Marwari, personally
inviting Jayal + 30 km to the shop's bridal collection. In a tier-3 radius this
format beats polished films — the owner's face + local dialect = trust, and
trust is the product in gold.

**Length target:** 20–25 seconds, spoken naturally. **Format:** 9:16 vertical,
half-body, shop counter backdrop, bridal tray in hand for the last third.

---

## The script (teleprompter — short lines, read aloud)

**0–3 s · Hook (smile, hands folded)**
> Ram Ram sa! 🙏
> Thanke Jayal mein — ekmatra bridal jewellery showroom aa gayo sa!

**3–12 s · Proof (gesture to the trays, one finger per point)**
> Best of the best bridal collection —
> fix vazan aur hallmark suddha sona re saathe,
> purana sona ri 100% value,
> aur live gold rate — Shivaa re khud re app par!

**12–18 s · Invitation (lift a bridal set toward the camera)**
> Ek baar aao — khud selection karo, pehen kar dekho.
> Free bridal design trial — kharidne ri koi majboori nahi.

**18–25 s · CTA (point down toward the WhatsApp button)**
> Niche WhatsApp button par ek click karo — ek baar baat karke dekho,
> Shivaa Jewels thanki kyian madad kar sake sa.
> Aaj hi baat karo sa! Ram Ram! 🙏

**Alternate opening if "ekmatra" (only) is not literally true for Jayal:**
> Ram Ram sa! 🙏 Jayal ri apni bridal jewellery shop — Shivaa Jewels!

---

## Filming rules

1. Vertical phone at eye level; half body (waist up); stand at the counter with
   bridal trays and the shop/name board visible behind.
2. Light on the FACE (face the window/lamp) — never shoot with light behind you.
3. Talk to the lens like a real customer at the counter. No acting, no rushing.
4. Record 3 full takes; pick the warmest; send the raw file on WhatsApp.
5. After receiving it the agent will: compress → burn clean Hindi subtitles
   (most viewers watch muted) → add the Shivaa logo end-card → export ad-ready
   1080×1920.

## Claims check (standing Shivaa law — true or don't say)

- "ekmatra bridal showroom" — only if literally the only one in Jayal (else use
  the alternate line above).
- OK as stated by the owner: fix vazan · hallmark suddha sona · purana sona ri
  100% value · live rate on the Shivaa app/site · free bridal design trial.
