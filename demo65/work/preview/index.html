How it's made, free: the image model re-renders the same photo with only the ring's position changed (same hand, light and background), giving a few keyframes. ffmpeg's optical-flow interpolation then invents every frame in between. No API key, no GPU, no subscription.

Best for short simple movements — sliding on, a hand turning, fingers flexing. Large motions would smear.
