      host → demo mode → on a public host codes silently fall to EMAIL
    · Admin → Settings → "Code delivery" now has a GATEWAY WIZARD:
      pick provider (MSG91 / Fast2SMS / APITxT / Textlocal / custom URL),
      paste key, save — it writes data/sms-config.json (0600, web-denied)
    · test SMS prints the gateway's RAW reply under the form (DLT/balance
      faults visible in one click); throttles now say how long to wait
    · shoppers see an honest line on the Passport: SMS or email channel
 3  Merchandising / UX layer (js/v107.js + css/v107.css, removable)

      feedback; all of it pauses in hidden tabs & reduced-motion
    · Quick View: scroll reset, focus trap, skip-to-buy link
    · Design Desk cards get a ⓘ full-details sheet (gross/less/net,
      fine-metal content, stones, making, GST, qty stepper)
    · NEW #/size-guide: true-scale ring circles (Indian sizes 8–26),
      50 mm ruler check, mm finder; saving a size pre-selects it in
      Quick View (writes the shv_ring_size key v104 already reads)

      navigated away (route-scoped timer)
